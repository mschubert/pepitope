# Create example peptide sheets for multiple samples

Create example peptide sheets for multiple samples

## Usage

``` r
example_peptides(valid_barcodes)
```

## Arguments

- valid_barcodes:

  A character vector of valid barcodes

A named list of peptide/minigene constructs with barcodes
